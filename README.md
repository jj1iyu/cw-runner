# JA CW Runner

スマホでもPCでも遊べる、CWコンテストのパイルアップ練習シミュレータです。ALL JA（国内）とDX（599＋CQゾーン）の2つのモードがあります。ホーム画面に追加するとアプリとして起動でき、オフラインでも練習できます。

以下のページから遊べます！！
https://jj1iyu.github.io/cw-runner/

## はじめかた

1. ページを開き、自分のコールサインを入れて「はじめる」
2. 右上の「開始」を押す
3. **ENTER** でCQを出すと、各局が呼んできます
4. 聞こえたコールを入力して **ENTER** → 相手のナンバーを入力して **ENTER** でQSO完了

時間が終わると結果画面が出て、得点・称号・実績が表示されます。

## 基本の操作

| 操作 | スマホ | PC（キーボード） |
|---|---|---|
| CQ／交換／TU を順に送る | ENTER | Enter |
| メッセージを個別に送る | CQ・交換・TU などのボタン | F1〜F8 |
| CALL欄とNR欄の切り替え | ⇄ | Space |
| カーソル移動 | ◀ ▶、文字をタップ | ← → |
| 1文字消す | ⌫ | Backspace |
| 送信を止める | 停止 | Esc |
| コール＋ナンバーを送る | ― | Insert または ; |

- ファンクションキーは F1 CQ、F2 交換、F3 TU、F4 自局、F5 相手、F6 B4、F7 ?、F8 NR? です。
- 送信中に別のキーを押すと、今の送信が終わってから続けて送ります。
- 送信中は受信音（ノイズや相手局）が消えます（セミブレイクイン）。
- コールに「?」を入れると部分コールになり、当てはまる局だけが応答します（例 JA1?）。
- ナンバーはカットでも入力できます（例 ALL JA：13M・1TM、DX：14・A4）。

## 設定

右上の「設定」から変更できます。変えた設定はその端末に保存されます。

### 自局

| 項目 | 初期値 | 説明 |
|---|---|---|
| コールサイン | ログイン時に入れたもの | 送信とランキングの名前に使われます（12文字まで） |
| 送るナンバー（ALL JA） | 10H | 都府県支庁ナンバー＋空中線電力 |
| 送るナンバー（DX） | 25 | CQゾーン（日本は25） |
| CQ文 | CQ TEST {MY} TEST | {MY} が自分のコールサインに置き換わります |
| TU文 | TU | QSO完了時に送る文 |
| 自局ナンバーをカットで送る | オン | 0→T、9→N で送ります（5NN 1TH など） |

### コンテスト

| 項目 | 初期値 | 選べるもの |
|---|---|---|
| コンテスト | ALL JA | ALL JA（国内）／DX（599＋CQゾーン）。次の開始から反映 |
| 相手局 | 実在局 | 実在局（過去のコンテスト参加局）／ランダム生成 |
| モード | シングルコール | シングルコール（1局ずつ）／パイルアップ（複数局が同時に呼ぶ） |
| 時間 | 5分 | 5分／10分／30分／60分／無制限 |
| アクティビティ | 4 | 1〜9。大きいほど呼んでくる局が増えます（パイルアップ時） |

### 受信音

| 項目 | 初期値 | 範囲 |
|---|---|---|
| 速度 | 24 WPM | 12〜50 WPM |
| 相手局の速度にばらつき | オン | オンだと相手局ごとに −7〜+4 WPM ずれます |
| ピッチ | 600 Hz | 300〜900 Hz |
| 帯域幅 | 400 Hz | 100〜800 Hz。狭いほど周りの局が聞こえにくくなります |
| 音量 | 70% | 0〜100% |
| 相手局の信号の強さ | 50% | 10〜100% |
| ノイズの量 | 5% | 0〜100% |
| モニター（自局送信音） | 35% | 0〜100% |

### コンディション

初期値はすべてオフです。オンにすると難しくなります。

| 項目 | 内容 |
|---|---|
| QSB | 信号の強さがゆっくり上下します（フェージング） |
| QRM | 近くの周波数で他の局が運用しています |
| QRN | 空電のバリバリというノイズが入ります |
| フラッター | オーロラ帯のような揺れた音になります |

### 初期設定に戻す

設定画面の「初期設定に戻す」を押すと、コールサイン以外が上の初期値に戻ります。

## 得点とランキング

- 得点は「有効QSO数 × マルチ」です。マルチは ALL JA が都府県支庁、DX がCQゾーンとエンティティです。
- コールやナンバーの誤り、NIL、DUP（交信済みの局）は0点です。DUP局には F6（B4）を返すと次へ進めます。
- 時間を決めたコンテスト（5〜60分）を最後まで走った記録が、ランキングに載ります。途中で停止した回と「無制限」は載りません。
- ランキングは ALL JA／DX、モード、時間ごとに分かれていて、各自の自己ベストが並びます。
- 1時間400局のペースを超える記録はランキングに載りません。
- 結果画面の「結果をコピー」で、成績を LINE などに貼り付けられます。

## アプリとして使う

- **iPhone／iPad**：Safari で開き、共有ボタン →「ホーム画面に追加」
- **Android**：Chrome で開き、メニュー →「アプリをインストール」（または「ホーム画面に追加」）
- **PC**：Chrome／Edge で開き、アドレスバー右のインストールアイコンをクリック

一度開けば、電波のない場所でも練習できます（ランキングへの記録は通信できるときだけ）。

## 困ったとき

- **音が出ない**：一度「開始」を押してください（ブラウザの仕組みで、ボタンを押すまで音が出せません）。iPhone は音量ボタンでメディアの音量も確認してください。
- **設定がおかしくなった**：設定画面の「初期設定に戻す」を押してください。
- **不具合や要望**：設定画面のいちばん下、または結果画面の「意見・不具合を送る」から送ってください。
